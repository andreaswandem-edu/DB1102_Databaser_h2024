## Om Emnet
Databaser (DB1102) ved Høyskolen Kristiania (1. semester). Emnet ga en innføring i relasjonsdatabaser, datamodellering og normalisering. Vi lærte å strukturere og koble sammen tabeller, samt bruke SQL til å hente, legge inn og endre data.
